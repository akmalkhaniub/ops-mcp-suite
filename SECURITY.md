# 🔐 Security Policy

## Supported Versions
Only the latest version of `ops-mcp-suite` on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability within `ops-mcp-suite` (particularly regarding secret exposure, credential leakage, or unauthorized tool execution):
1. Please do NOT open a public issue.
2. Email details of the vulnerability to `security@akmalkhan.dev` with reproduction steps.
3. We will acknowledge receipt within 48 hours and coordinate a security release.
